# Hello!

This is my Windows dev kit.
It contains various scripts, command aliases, configs, etc. for when I'm developing on Windows.
Feel free to take a look.

## Installing

The devkit installs to `~/.devkit` for the current user.

**From a clone:** run `setup.bat`.

**Without cloning:** open [`dist/devkit-install.ps1`](dist/devkit-install.ps1) on GitHub, click "Copy raw file", and paste into PowerShell.
